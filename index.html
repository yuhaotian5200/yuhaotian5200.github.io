MYAI Drive Sync

A personal file-sync utility for a single user.

What this app does

MYAI Drive Sync is a small desktop tool. It copies plain-text files that already exist on the owner's own computer into folders inside the owner's own Google Drive. It does not access, read, or upload anyone else's data.

It runs on the owner's Mac on a daily schedule and uses the Google Drive API with the owner's own authorisation.

What it accesses

  • Text files stored locally on the owner's computer
  • One Google Drive account, granted by the owner during setup

It creates and updates files only inside designated folders in that Drive account. It never deletes files. It does not read files that the owner has not placed in its source folders.

Who uses it

This is a private utility with a single user, the account owner. It is not distributed, not offered as a service, and has no other users.
